## No beluga-ext-sdk Dependency
This extension does NOT use `beluga-ext-sdk`. It's a local extension compiled into the binary.

## Standalone Build: NOT POSSIBLE (by design)
Go's `internal` package restriction prevents external modules from importing `internal/*` packages. This is expected — local extensions are **source distributions** that get installed INTO Beluga's source tree at `internal/extensions/clickup/` via `beluga extend install`. Once inside the module, `internal/` packages resolve correctly.

## Install Flow
```
beluga extend install ./beluga-ext-clickup
  → copies *.go to internal/extensions/clickup/
  → go mod tidy (picks up any new deps)
  → go build ./... (verifies build)
  → registers in lookupBuiltinExtension()
  → add config to beluga.yaml
  → beluga start
```
